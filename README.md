Vice After Dark — an offline web app that turns any photo and caption into a GTA 6-style neon-night poster cover, exported as PNG in 1080x1080, 1080x1350, 1920x1080 and story sizes. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
python3 -m http.server --directory app 8080
```

Then open http://localhost:8080 in desktop Chrome. Load a photo, pick a layout and grade, edit the caption, export PNG.
