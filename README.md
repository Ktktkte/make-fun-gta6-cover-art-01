Vice Sunset — a GTA 6-style cover art maker. Load a photo (or several),
crop and position each one across a multi-panel Vice City sunset poster,
type a bold caption, and export the cover as a PNG to share — in
1080 x 1080, 1080 x 1350 or 1920 x 1080. Everything runs offline in the
browser from these static files; photos never leave the machine. Original
artwork and lettering only — no Rockstar Games logos, artwork or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
